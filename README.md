# Dictation

A local dictation project that leverages the **Whisper Turbo** model for high-quality transcription directly from the terminal, complete with keyboard shortcuts.

## Origin Story
The idea for this project came from using Wispr Flow. After hitting the paywall and being prompted to get a subscription, I realized this was totally possible to build locally. Rather than paying for a subscription, I chose to create my own simply and tailored to my exact workflow.

## Features
- **Local Whisper Turbo Engine:** Fast, local transcription running directly via the terminal.
- **Terminal Shortcuts:** Seamlessly start and stop dictation without leaving your workflow.
- **Post-Transcription Analysis (WIP):** 
  - Automatically analyzes what was transcribed to apply labels.
  - Uses context to correct sentences and improve readability.
  - Optimized for note-taking.

## Use Case
While currently a Work In Progress (so it's not at 100% perfect accuracy yet), it is incredibly helpful for letting yourself freely listen to a professor or meeting. You can take the notes that naturally come to you based on their importance, while the tool automatically transcribes the actual talk. 

Later, you can feed these transcripts into tools like ChatGPT or Gemini to build upon them, summarize, and learn better.
